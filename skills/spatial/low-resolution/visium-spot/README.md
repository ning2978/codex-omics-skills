# spatial/low-resolution/visium-spot

10x Visium spot-level 空间转录组。

| Skill | 用途 |
|-------|------|
| `st-data-preparation` | Visium 原始数据或 Seurat/RCTD 空间对象到标准化 h5ad。 |
| `algorithm-cell2location` | cell2location 参考模型、空间模型、参数选择和输出校验。 |
| `algorithm-rctd` | RCTD 反卷积输入、运行和输出校验。 |
| `cell2location-result-visualization` | cell2location `spatial.h5ad` 输出汇总和作图。 |
| `stlearn-spatial-trajectory` | stLearn 形态校正、空间轨迹和 stLearn CCI。 |
| `visium-spot-squidpy-proximity` | spot-level anchor-neighbor proximity 分析。 |
| `visium-spot-niche-annotation` | spot niche / CellCharter cluster 注释。 |

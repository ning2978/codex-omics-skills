# spatial

空间组学 skill。先区分通用路由、低精度 spot-level 空间转录组和高精度 bin/cell-level 空间数据。

| 分组 | 范围 |
|------|------|
| `shared/` | 跨平台 ST 路由、通用 workflow、CellCharter/COMMOT/Tangram/Squidpy 等共享算法。 |
| `low-resolution/visium-spot/` | 10x Visium spot-level 空间转录组。 |
| `high-resolution/visium-hd/` | 10x Visium HD binned 空间转录组。 |
| `high-resolution/xenium/` | 10x Xenium cell-level 空间原位数据。 |
| `high-resolution/codex-imc/` | CODEX/IMC/mIHC cell-level 空间蛋白数据。 |

# spatial/shared

空间组学跨平台路由、workflow 和通用算法。

| Skill | 用途 |
|-------|------|
| `workflow-st-analysis` | ST 项目阶段检测、稳定契约，以及从原始输入到分析就绪输出的路由。 |
| `workflow-deconvolution-run` | 反卷积运行生命周期：准备、启动、监控、完成检查。 |
| `algorithm-cellcharter` | CellCharter 空间图、邻域聚合、聚类和输出校验。 |
| `algorithm-commot` | COMMOT 空间 ligand-receptor 通讯。 |
| `algorithm-tangram` | Tangram scRNA 到空间映射。 |
| `squidpy-spatial-image-features` | Squidpy 图像容器、空间图、空间统计和 LR 图。 |
